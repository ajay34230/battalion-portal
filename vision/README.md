# VISION — personal AI agent for Android

Work in progress on branch `vision/phase-0` of this repository (separate from the battalion portal).
Read `docs/KNOWN_LIMITATIONS.md` first: it lists what works, what is rule-based, and what is unverified on real devices.
Build: GitHub Actions workflow `VISION Android build` (compiles, runs unit tests, builds a debug APK).
Works on any Android 8+ phone; capabilities are selected by detected RAM/ABI tier.
