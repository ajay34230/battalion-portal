# Device compatibility

Target: any Android 8.0+ (minSdk 26) 64-bit ARM phone. Tiers by RAM (LITE <3 GB, STANDARD <6 GB, PERFORMANCE). iQOO 7 (owner-reported Snapdragon 870, 8 GB + virtual RAM, Android 14) = PERFORMANCE tier. Details in ANDROID_COMPATIBILITY.md and DEVICE_PROFILE_IQOO7.md.
On-phone compilers: Python, Node, Go, Rust, C/C++, PHP, Ruby, Java/Gradle (JVM projects only) via Termux; Android SDK/APK builds are not possible on ARM phones. Not tested on any device yet.
