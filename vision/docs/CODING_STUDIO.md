# Coding Studio

Open it from More → Coding Studio. Projects list (new from template or empty), Dev tools tab. Inside a project: **Files** (add/delete, Check, Export ZIP), **Editor** (monospace, syntax colours, find with match count, outline chips for functions/classes, Save), **Preview** (sandboxed WebView, page picker, console), **Run** (Termux, confirmed), **Ask VISION** (build/change, research, compare approaches, find & fix errors), **Tools** (what this project needs), **History** (snapshots with restore, activity log).
Projects live in the app's private storage (`files/projects`). Offline: everything except research, installs and model downloads works without internet.
Known gaps: no multi-file search, no git UI, no stop button for Termux runs (30 s limit applies), no APK build on the phone.
