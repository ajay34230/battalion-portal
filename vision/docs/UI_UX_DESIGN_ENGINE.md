# UI/UX design engine

Built: the VISION app UI itself follows a small design system (see DESIGN_SYSTEM.md); the website and dashboard templates ship with responsive, light/dark, token-based CSS.
Not built: automated design-reference research (Dribbble/Behance/Awwwards are not machine-readable), screenshot capture and visual inspection of generated apps, multi-screen-size testing, open-source component discovery. The model can be asked to restyle files through "Ask VISION", but its visual quality is unverified.
